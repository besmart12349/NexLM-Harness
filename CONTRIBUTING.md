# Contributing to NexLM Harness

English | [中文](CONTRIBUTING.zh.md)

Thank you for your interest in contributing to NexLM Harness.

NexLM Harness is still at an early stage and under active development. External pull requests may not be accepted yet. You can still help by opening issues, sharing feedback, and building plugins.

## Ways to help

- Report bugs and UX issues in this repository.
- Improve docs and examples.
- Build plugins and share them with the NexLM community.

See [docs/development.md](docs/development.md) and [AGENTS.md](AGENTS.md).
